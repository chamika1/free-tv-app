# Free TV

Free TV is a cross-platform TV, movie, and series player available for Android and Windows.

## Downloads

Download the latest installers from the **[GitHub Releases](../../releases/latest)** page.

| Platform | Package | Requirements |
|---|---|---|
| Android | `Free-TV-Android-v1.0.2.apk` | Android 8.0 or newer |
| Windows | `Free-TV-PC-Windows-x64-v1.0.0.zip` | 64-bit Windows 10/11 and Microsoft Edge WebView2 Runtime |

## Android installation

1. Download the APK from Releases.
2. Allow installation from your browser or file manager when Android asks.
3. Open the APK and select **Install**.

Package ID: `digital.fflow.freetv`

## Windows installation

1. Download the Windows ZIP from Releases.
2. Extract the ZIP.
3. Run `Free TV.exe`.
4. If Windows SmartScreen appears, review the publisher warning before choosing to run it.

The Windows build is self-contained, but it uses the Microsoft Edge WebView2 Runtime available on current Windows 10/11 systems.

These clients currently connect to the hosted Free TV web service. Availability depends on that service and its upstream content providers. A future app update may be required if the service address changes.
