# Free TV v1.0.2

First public GitHub release of the Free TV Android and Windows clients.

## Included downloads

- **Free-TV-Android-v1.0.2.apk** — Android 8.0+ app, package `digital.fflow.freetv`
- **Free-TV-PC-Windows-x64-v1.0.0.zip** — self-contained Windows 10/11 x64 desktop app

## Android highlights

- Live TV, movies, and TV-series access through the Free TV service
- In-app update support
- Popup and pop-under blocking
- Safer top-level navigation handling
- Android 8.0 minimum; Android 15 target

## Windows highlights

- Native Windows WebView2 shell
- Home, Back, Reload, and fullscreen controls
- Popup and external-redirect blocking
- Windows 10/11 x64 support
