# Free TV v1.0.4

Android compatibility and in-app updater release. The Windows client remains at v1.0.0.

## Included downloads

- **Free-TV-Android-v1.0.4.apk** — Android 8.0+ app, package `digital.fflow.freetv`

## Android highlights

- Live TV, movies, and TV-series access through the Free TV service
- In-app update support
- Popup and pop-under blocking
- Safer top-level navigation handling
- Provider iframe sandbox kept OFF for playback compatibility
- Automatic update check retries on slow mobile networks
- Cache-bypassing update manifest requests and a manual **App update** control
- Android 8.0 minimum; Android 15 target
